# 우리교회

교회 묵상 나눔 · 기도제목 · 공지 · 주보를 한 곳에서 보는 안드로이드 앱.
여러 교회가 각자의 공간으로 쓸 수 있고, 목사님이 성도·셀·직분·권한을 관리합니다.

```
우리교회어플/
├── android/        안드로이드 앱 (Kotlin + Jetpack Compose)  ← Android Studio 로 여는 폴더
├── server/         Cloudflare Workers API + D1 스키마 + 데이터 이전 스크립트
├── legacy-web/     예전 웹앱 (아이폰·PC 쓰시는 분들용으로 그대로 살려 둠)
└── README.md
```

---

## 1. 서버 먼저 (Cloudflare)

> 한 번만 하면 됩니다. 무료 범위 안에서 돌아갑니다.

```bash
cd server
npm install
npx wrangler login                 # 브라우저가 열립니다

# 데이터베이스 만들기
npx wrangler d1 create woori-church
#  → 나온 database_id 를 wrangler.toml 의 database_id 에 붙여넣기

# 주보 파일 보관함 만들기
npx wrangler r2 bucket create woori-church-files

# 표 만들기 (여러 번 돌려도 안전)
npm run db:init

# 올리기
npm run deploy
#  → https://woori-church.<계정이름>.workers.dev 주소가 나옵니다
```

**비용**: D1 5GB · R2 10GB · Workers 하루 10만 요청까지 무료.
교회 수십 곳 규모까지는 월 0원이고, 넘어가면 Workers Paid 월 $5 입니다.
D1 은 **Time Travel** 로 지난 7일(유료는 30일) 중 아무 시각으로나 되돌릴 수 있어
따로 백업을 돌리지 않아도 됩니다.

## 2. 앱 (Android Studio)

1. Android Studio → **Open** → 이 폴더의 **`android`** 를 고릅니다
2. `android/app/build.gradle.kts` 에서 **한 줄만** 서버 주소로 바꿉니다

```kotlin
buildConfigField("String", "API_BASE", "\"https://woori-church.내계정.workers.dev\"")
```

3. Gradle Sync → ▶ 실행

| | |
|---|---|
| 언어 · UI | Kotlin, Jetpack Compose (Material 3) |
| 최소 안드로이드 | 8.0 (API 26) |
| 대상 | Android 15 (API 35) |
| 통신 | OkHttp + kotlinx.serialization |
| 기기 저장 | DataStore (토큰, 글씨 크기, 묵상 본문 링크, 임시저장) |

## 3. 첫 교회 만들기

1. 앱 실행 → **우리 교회 가입하기** → 교회 정보와 담임목사 정보를 넣고 신청
2. 아직 승인 전이라 로그인이 안 됩니다. 아래를 한 번 실행해 **본인을 운영자로** 지정합니다

```bash
cd server
npx wrangler d1 execute woori-church --remote --command \
  "update churches set status='approved' where id=1;
   update members set is_platform_admin=1 where church_id=1 and role='owner';"
```

3. 앱에 로그인하면 홈에 **[교회 등록 신청 심사]** 가 생깁니다.
   이제부터 다른 교회 신청은 앱 안에서 승인/거절하면 됩니다.

## 4. 권한이 어떻게 나뉘나

**직분은 호칭, 권한은 목사님이 사람마다 켜고 끄는 스위치**입니다. 서로 별개예요.

| 할 수 있는 일 | 담임목사 | 관리 권한 | 셀장 | 성도 |
|---|:--:|:--:|:--:|:--:|
| 묵상 나눔 · 기도제목 · 댓글 | ✓ | ✓ | ✓ | ✓ |
| 우리 셀 현황 보기 | ✓ | ✓ | ✓ | |
| 성도 / 셀 관리, 직분 지정 | ✓ | ✓ | | |
| 가입 신청 승인, 비밀번호 초기화 | ✓ | ✓ | | |
| 공지 · 주보 올리기 | ✓ | ✓ | | |
| **권한 주기** | ✓ | | | |
| **나눔 범위 바꾸기** | ✓ | | | |
| **교회 줌 링크 설정** | ✓ | | | |

**나눔 범위**는 사람마다 따로입니다.

- `본인 셀만` — 기본값. 자기가 속한 셀 안에서만 나눠집니다
- `셀 선택 가능` — 나눌 때 셀을 고를 수 있고 **모든 셀에 나누기**도 됩니다
  (목사·사모가 기본으로 이쪽이고, 목사님이 다른 분께도 열어 줄 수 있습니다)

직분은 **목사 / 사모 / 장로 / 안수집사 / 권사 / 집사 / 성도** 중에서 목사님이 지정합니다.
처음 가입하면 모두 `성도` 입니다.

## 5. 이단 교회가 못 들어오게 하는 방법

자동으로 완벽히 거르는 방법은 없습니다. 위장 교회는 평범한 이름과 정상 교단명을
그대로 쓰고 들어오기 때문입니다. 그래서 3단으로 막습니다.

1. **자동 키워드 차단** — `schema.sql` 의 `blocked_keywords` 표. 이단 규정 단체 명칭과
   교주 이름이 들어가면 신청 자체가 안 됩니다. 새 키워드는 이렇게 넣습니다:
   ```bash
   npx wrangler d1 execute woori-church --remote --command \
     "insert or ignore into blocked_keywords values('추가할말','메모');"
   ```
2. **정보 요구** — 교회명·주소·전화·**소속 교단**·담임목사 성함·안수 교단·홈페이지.
   핵심은 **교단 공식 교회검색 명부와 대조**하는 것입니다. 이단은 그 명부에 없습니다.
3. **사람이 승인** — 심사 화면에서 위 정보를 보고 승인/거절. 애매하면 전화 한 통.

**초대 코드**도 있습니다. 이미 쓰고 있는 교회 목사님이 설정에서 코드를 받아
아는 교회에 알려 주면, 그 신청은 신뢰 체인이 생겨 심사가 빨라집니다.

> ⚠️ 거절 사유는 신청자에게 알려지지 않게 해 두었습니다.
> 특정 교회에 "이단이라 거절"이라고 통보하면 명예훼손 시비가 붙을 수 있어서입니다.
> 약관에는 "승인제이며 승인 여부와 사유를 개별 안내하지 않습니다"로 적어 두세요.
> (법률 자문이 아니라 실무상 안전한 쪽을 택한 것입니다.)

## 6. 예전 나눔광장 데이터 옮기기

```bash
cd server
node migrate-from-supabase.mjs \
  --url https://vadzwqrlsjatogxrmony.supabase.co \
  --key <Supabase service_role 키> \
  --church 1 --cell "본교회"

# 만들어진 migrate.sql 을 눈으로 확인한 뒤
npx wrangler d1 execute woori-church --remote --file=./migrate.sql
```

성도·묵상·댓글·좋아요가 그대로 넘어옵니다.
다만 **비밀번호는 방식이 달라 옮기지 못합니다.** 넘어온 분들은 모두
'비밀번호 초기화' 상태가 되니, 목사님이 성도 관리에서 임시 번호를 발급해
알려 주시면 첫 로그인 때 새로 정하게 됩니다.

`service_role` 키는 이 작업에만 쓰고 바로 지우세요. 앱에는 절대 넣지 않습니다.

## 8. 아이폰 쓰시는 분들

안드로이드 앱만으로는 아이폰 교인이 못 씁니다.
`legacy-web/index.html` 이 예전 웹앱 그대로 남아 있으니, 당분간은
웹 주소를 함께 알려 주시면 됩니다. (서버가 달라 데이터는 따로 쌓입니다 —
아이폰 쪽까지 한 데이터로 묶으려면 이 웹앱을 새 API 에 맞춰 고쳐야 합니다.)
